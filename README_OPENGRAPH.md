## ⚡ Что важно знать

### ✅ Работает отлично:

- Главная страница
- Все статические страницы
- Facebook, Instagram, WhatsApp, Telegram
- Изображения загружаются правильно
- Метаданные корректные

### ⚠️ Ограничения:

**Мультиязычность:**
- Боты соцсетей НЕ выполняют JavaScript
- Всегда показывается русская версия из `index.html`
- Кыргызское изображение не используется ботами

**Решения:**
1. **Простое:** Создать универсальное изображение с обоими языками
2. **Без текста:** Изображение только с логотипом (универсально)
3. **Продвинутое:** Миграция на Next.js для SSR

👉 **Подробнее:** `UNIVERSAL_OG_IMAGE_SOLUTION.md`

### 🔄 Кэширование:

Социальные сети кэшируют метаданные:
- **Facebook:** несколько часов
- **Telegram:** 2-3 часа  
- **WhatsApp:** несколько часов
- **Instagram:** аналогично WhatsApp

**Как обновить:**
- Facebook: "Scrape Again"
- Telegram: добавить `?v=2` к URL
- Или подождать несколько часов
