# Решение проблемы с отображением изображений Open Graph

## Проблема
Метаданные Open Graph (title, description) отображаются, но **изображение не загружается** в социальных сетях.

## Что было исправлено

### ✅ 1. Обновлены размеры изображений в метатегах
- Старые значения: 1200x630px (неправильные)
- **Новые значения: 1672x941px** (фактический размер ваших изображений)

### ✅ 2. Добавлен метатег `og:image:secure_url`
Этот тег важен для HTTPS-сайтов. Многие социальные сети требуют его.

```html
<meta property="og:image:secure_url" content="https://ak-kagaz.vercel.app/opengraph/og-image-ru.png" />
```

### ✅ 3. Настроены HTTP headers в Vercel
В `vercel.json` добавлены заголовки для правильной раздачи изображений:
- `Cache-Control` - для кэширования
- `Content-Type: image/png` - правильный MIME-тип

### ✅ 4. Создана тестовая страница
Файл `/og-test.html` для изолированного тестирования Open Graph.

## Частые причины проблем

### 🔴 Причина 1: Неправильный URL изображения

**Симптомы:**
- Метатеги есть, но изображение не загружается
- В валидаторе ошибка "Image could not be downloaded"

**Решение:**
- URL должен быть **абсолютным**: `https://...`
- Изображение должно быть **доступным** публично
- Проверьте URL в браузере

### 🔴 Причина 2: Неправильный размер изображения

**Симптомы:**
- Изображение есть, но не отображается в preview
- Валидатор показывает предупреждения

**Решение:**
- Рекомендуемый размер: **1200x630px** или **1200x627px**
- Ваш размер: **1672x941px** (тоже работает)
- Минимум: 200x200px
- Максимум размер файла: 8MB

### 🔴 Причина 3: Неправильный формат изображения

**Симптомы:**
- Файл существует, но не распознаётся

**Решение:**
- Используйте **PNG** или **JPEG**
- Проверьте, что файл не повреждён
- Убедитесь, что расширение соответствует формату

### 🔴 Причина 4: Кэширование

**Симптомы:**
- Изображение обновлено, но показывается старое
- Или не показывается совсем

**Решение:**
- Facebook: используйте "Scrape Again"
- Telegram: добавьте `?v=2` к URL
- Или подождите несколько часов

### 🔴 Причина 5: CORS или Security Headers

**Симптомы:**
- Изображение открывается в браузере, но не в соцсетях

**Решение:**
- Проверьте CORS headers (обычно не проблема для статических файлов на Vercel)
- Убедитесь, что нет редиректов
- Проверьте, что используется HTTPS

### 🔴 Причина 6: JavaScript рендеринг (React SPA)

**Симптомы:**
- Метатеги обновляются при открытии страницы в браузере
- Но социальные сети видят только начальный HTML

**Решение:**
- Социальные сети **НЕ выполняют JavaScript**
- Они читают только HTML из первоначального ответа сервера
- Поэтому метатеги должны быть в `index.html`
- Динамическое обновление через JS работает только для пользователей, но **не для ботов соцсетей**

**Наше решение:**
- Базовые метатеги есть в `index.html` ✅
- JavaScript обновляет их для пользователей ✅
- Но для share preview используются изначальные метатеги из HTML ✅

- [ ] Изображения существуют в `frontend/public/opengraph/`

- [ ] Метатеги в `index.html` содержат правильный URL
- [ ] URL изображений - абсолютные (https://...)
- [ ] Добавлен метатег `og:image:secure_url`

## Команды для проверки

### Локальная проверка перед deploy:

```bash
cd frontend

# Сборка
npm run build

# Проверка, что изображения скопировались
ls dist/opengraph/

# Запуск preview
npm run preview
```

Откройте http://localhost:4173 и проверьте метатеги в DevTools.

### После deploy на Vercel:

```bash
# Проверка доступности изображения
curl -I https://ak-kagaz.vercel.app/opengraph/og-image-ru.png

# HTTP/2 200
# content-type: image/png
```

## Дополнительные рекомендации

### 1. Используйте правильный размер изображений
Хотя ваш размер (1672x941) работает, рекомендуется оптимизировать до 1200x630px:
- Меньший размер файла
- Быстрее загружается
- Стандарт Open Graph

### 2. Оптимизируйте изображения
```bash
# Если у вас установлен ImageMagick:
magick og-image-ru.png -resize 1200x630 -quality 90 og-image-ru-optimized.png
```

### 3. Проверяйте в нескольких валидаторах
Разные соцсети по-разному обрабатывают метатеги:
- Facebook - самый строгий
- Twitter - свои правила для cards
- LinkedIn - требует профессиональные изображения
- Telegram - самый либеральный

### 4. Мониторьте изменения
После каждого изменения метаданных:
1. Deploy на Vercel
2. Проверка в Facebook Debugger (обязательно!)
3. Проверка в Telegram
4. Очистка кэша при необходимости
