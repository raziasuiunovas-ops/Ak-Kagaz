## 🎯 Краткое резюме

**AK KAGAZ** — полнофункциональная PWA платформа для оптово-розничного магазина канцтоваров в г. Ош, Кыргызстан.

### Ключевые функции

✅ **Для покупателей:**
- Каталог товаров с фильтрами и поиском
- Варианты товаров (цвет, размер, формат)
- Корзина с автоматическим пересчётом цен
- Оптовые и розничные цены
- Оформление заказов (доставка/самовывоз)
- История заказов и повтор заказа
- Отзывы на товары
- Список школьных принадлежностей

✅ **Для сотрудников:**
- Управление каталогом товаров
- Управление заказами
- Складской учёт
- Поступления от поставщиков
- Управление клиентами
- Аналитика и отчёты
- Система ролей и разрешений

✅ **Технические требования:**
- PWA с offline поддержкой
- Двуязычный интерфейс (RU/KY)
- Адаптивный дизайн
- Безопасность и защита данных
- RBAC система управления доступом

1. ✅ Monorepo структура с pnpm workspaces
2. ✅ Frontend: React 19 + Vite + TypeScript
3. ✅ Backend: NestJS + TypeScript
4. ✅ Prisma ORM конфигурация
5. ✅ PWA настройка
6. ✅ Роутинг с React Router DOM

8. ✅ Testing infrastructure
9. ✅ Development guidelines (AGENTS.md)
